# Superseded v0.1 outputs

The flags.json, metrics.json, results.parquet and dashboard.png directly in this
directory are historical demonstration artifacts. They are not scientific evidence.
The old harness executed an imitation detector, reused a single payload, assigned
unsupported category labels, and hardcoded privacy and agent-success fields.
No conclusions about extension recall, privacy, preservation, or agent protection
should be drawn from these files. New schema-v2 runs have timestamped directories
and measured observations. This notice preserves the original evidence trail.
